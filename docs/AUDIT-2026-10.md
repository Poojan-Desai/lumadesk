# Pre-change audit — 2026-10-24

Scope: native Swift application; inspected DocumentImporter, RetrievalEngine, WorkspaceModel, validation suite and benchmark documentation before edits. Existing local baseline includes prior unpublished vector invalidation and reproducible retrieval benchmarking.

Verified by inspection: importing is explicit and snapshot based, not filesystem monitoring. Original paths are intentionally not retained. Actor index rebuild already invalidates vectors when passage text changes and removes deleted entries. Page provenance exists. JSON decoding failures block persistence, but syntactically valid duplicate document IDs, duplicate/invalid page numbers, and oversized records bypass validation; they can produce ambiguous stable passage IDs and citations. Atomic JSON writes do not explicitly limit file permissions.

Priority: shared validated library store with safe, atomic private writes; reject ambiguous provenance and corrupt structured records without overwriting. Add real save/reopen/corruption and rename/page-reorder/OCR citation tests. Preserve snapshot privacy and existing source schema.

Deferred: automatic file watching/relocation/security bookmarks (requires product decision to persist original locations); import cancellation/progress redesign; large-corpus profiling; broader VoiceOver/product redesign. No unsupported production claims. Baseline and final commands/results are recorded in the evidence report.
